# 410 gone SEO&GEO tools

Extension Chrome (Manifest V3) pour analyser rapidement une page web.

## Fonctionnalités

- **Perf** : TTFB, taille de transfert du document principal, et compression HTTP.
- **Structure** : surbrillance des Hn, zones HTML5, liens internes et externes.
- **Tech** : activation/désactivation du chargement JS et CSS (par onglet, avec rechargement).
- **Redirection** : affichage de la chaîne de redirections ou confirmation d'un statut final 200.
- **Configuration** : page d'options avec couleurs paramétrables.

## Installation locale

1. Ouvrir `chrome://extensions`.
2. Activer le mode développeur.
3. Cliquer sur **Charger l'extension non empaquetée**.
4. Sélectionner ce dossier.
